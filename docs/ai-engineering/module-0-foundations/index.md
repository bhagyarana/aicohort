# Module 0: Foundations

This module ensures you have the minimum viable baseline before every other module in this track. It is not a full Python course — it is a targeted review of the exact skills that AI engineering breaks without. If you can already do everything in the checklist below, skip ahead to [Module 1](/learn/ai-engineering/module-1-llm-fundamentals).

## What You'll Learn

- Write efficient Python data pipelines using generators and batch processing
- Call external APIs asynchronously with proper rate limiting and retry logic
- Handle JSON and streaming responses in real-world patterns
- Understand vectors and dot products geometrically, not just symbolically
- Read probability distributions and softmax outputs as confidence scores

## Prerequisites

- Basic Python (variables, functions, loops, conditionals)
- Comfort with the command line and `pip install`
- No prior AI or ML experience required

## Time Estimate

~2 hours
