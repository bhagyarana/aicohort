# Resources: Multimodal Systems

## Papers & Research

- **[CLIP: Learning Transferable Visual Models From Natural Language Supervision](https://arxiv.org/abs/2103.00020)** (Radford et al., OpenAI, 2021) — The foundational paper that created the shared image-text embedding space. Essential reading for understanding how VLMs work.

- **[Flamingo: a Visual Language Model for Few-Shot Learning](https://arxiv.org/abs/2204.14198)** (Alayrac et al., DeepMind, 2022) — Influential architecture for connecting frozen vision encoders to language models via cross-attention. Introduced the gated cross-attention approach.

- **[LLaVA: Visual Instruction Tuning](https://arxiv.org/abs/2304.08485)** (Liu et al., 2023) — Showed that a lightweight adapter between CLIP and an LLM, trained on GPT-4-generated instruction data, achieves strong visual understanding. The open-source VLM baseline.

- **[LLaVA-1.5](https://arxiv.org/abs/2310.03744)** (Liu et al., 2023) — Improved LLaVA with better training, stronger performance across benchmarks. Practical open-source alternative to GPT-4V.

- **[Whisper: Robust Speech Recognition via Large-Scale Weak Supervision](https://arxiv.org/abs/2212.04356)** (Radford et al., OpenAI, 2022) — The paper behind Whisper. Explains how large-scale diverse audio training leads to robust transcription across accents, noise, and languages.

- **[DALL-E 3: Improving Image Generation with Better Captions](https://cdn.openai.com/papers/dall-e-3.pdf)** (OpenAI, 2023) — Describes how training on highly descriptive captions (generated by GPT-4) dramatically improves text-following in image generation.

- **[Denoising Diffusion Probabilistic Models (DDPM)](https://arxiv.org/abs/2006.11239)** (Ho et al., 2020) — The paper that launched the modern diffusion model era. Formal mathematical treatment of the forward/reverse process.

## Official Documentation

- **[OpenAI Vision API](https://platform.openai.com/docs/guides/vision)** — Official guide for sending images to GPT-4o. Covers URL vs base64, detail levels, pricing, and limitations.

- **[Anthropic Claude Vision](https://docs.anthropic.com/en/docs/build-with-claude/vision)** — Claude's vision capabilities documentation. Covers image formats, multi-image inputs, and best practices.

- **[OpenAI Whisper API](https://platform.openai.com/docs/guides/speech-to-text)** — Transcription and translation endpoint documentation.

- **[OpenAI Text-to-Speech API](https://platform.openai.com/docs/guides/text-to-speech)** — TTS-1 and TTS-1-HD endpoints, voices, and streaming audio.

- **[HuggingFace Transformers — Vision Models](https://huggingface.co/docs/transformers/en/index#vision)** — Documentation for running open VLMs (LLaVA, Idefics, BLIP-2) locally.

## Videos & Courses

- **[Andrej Karpathy — Intro to Large Language Models](https://www.youtube.com/watch?v=zjkBMFhNj_g)** — While not multimodal-specific, gives the best intuition for how tokens and embeddings work, which directly applies to understanding patch embeddings in VLMs.

- **[Stable Diffusion Tutorial — Computerphile](https://www.youtube.com/watch?v=1CIpzeNxIhU)** — Clear intuitive explanation of how diffusion models work without heavy math.

- **[Two Minute Papers — Vision-Language Models](https://www.youtube.com/c/TwoMinutePapers)** — Short summaries of recent multimodal papers including DALL-E, Flamingo, and GPT-4V.

## Tools to Know

| Tool | What It Does | When to Use |
|------|-------------|-------------|
| **Pillow (PIL)** | Python image processing | Resize, crop, convert images before API calls |
| **pdf2image** | Convert PDF pages to images | Before sending PDFs to VLM |
| **Tesseract / pytesseract** | OCR — image to text | Text extraction from scanned documents |
| **OpenCV** | Computer vision library | Color extraction, image preprocessing, object detection |
| **whisper (local)** | Run Whisper locally | Private audio data, offline use |
| **ElevenLabs API** | High-quality TTS, voice cloning | Production voice applications |
| **Coqui TTS** | Open-source TTS | Self-hosted voice output |
| **CLIP (HuggingFace)** | Image-text embeddings | Multimodal search, zero-shot classification |
| **Diffusers (HuggingFace)** | Run diffusion models locally | Image generation without commercial APIs |
| **LangChain Vision** | Multimodal chain integrations | Integrating VLMs into LangChain pipelines |
